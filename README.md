# customer_behaviour_analysis
# Customer Purchase Behaviour & Insights Tracker

## Overview
This repository contains an end-to-end Data Analytics project designed to track, clean, and analyze over 3,900 customer transactions[cite: 1]. The primary goal of this project is to transform raw purchase data into actionable business intelligence by migrating text-based records into a relational database, performing exploratory data analysis, and delivering interactive visualizations for strategic decision-making.

This project covers the full data lifecycle: data ingestion and exploratory analysis in **Python**, robust schema design and structured querying in **MySQL**[cite: 1], interactive dashboard development, and automated stakeholder reporting using **Generative AI (Gemini)**[cite: 1].
